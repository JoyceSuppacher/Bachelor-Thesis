# Bachelor-Thesis


## Project
Bioinformatic analysis of dinucleotide patterns in rAAV2 vectors and their 
influence on packaging efficiency. Six transgene variants (lambda, wt-fragments, 
M1–M4) were analyzed by Oxford Nanopore sequencing and ddPCR.


## Requirements
- R version ≥ 4.2
- Required packages (see 00_setup.Rmd)
